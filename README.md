    # 🐍 Python para Ciencia de Datos y Big Data desde CERO

Repositorio oficial de la serie **Python para Ciencia de Datos y Big Data desde CERO** de **FreeCode**.

En esta serie aprenderemos Python desde cero con un enfoque completamente práctico y orientado a **Ciencia de Datos, análisis de información y Big Data**.

La idea no es memorizar código, sino entender **qué hacemos, por qué lo hacemos y cómo aplicarlo a problemas reales**.

---

## 🎯 Objetivo

Aprender las bases de Python necesarias para posteriormente trabajar con datos, analizarlos, limpiarlos, transformarlos y construir soluciones orientadas al mundo de los datos.

A medida que avancemos llegaremos a temas como:

- 🐍 Python
- 📊 Análisis de datos
- 🧹 Limpieza y transformación de datos
- 🐼 Pandas
- 🔢 NumPy
- 📈 Visualización de datos
- 📁 Archivos CSV
- 🗄️ Bases de datos
- 🤖 Machine Learning
- ⚡ Big Data
- 🚀 Procesamiento de grandes volúmenes de información

---

## 📚 Contenido de la serie

### 🐍 01 - Fundamentos de Python

Comenzaremos desde cero con los conceptos fundamentales de Python que realmente necesitaremos para trabajar posteriormente con datos.

Temas:

- Variables
- Tipos de datos
- Strings
- Números
- Booleanos
- Listas
- Tuplas
- Diccionarios
- Condicionales
- Bucles
- Funciones
- Manipulación de datos

📂 `01_fundamentos_python/`

---

### 📊 02 - Python y Pandas

Comenzaremos a trabajar con información real utilizando Pandas.

Aprenderemos a:

- Importar Pandas
- Leer archivos CSV
- Explorar datasets
- Conocer filas y columnas
- Revisar tipos de datos
- Seleccionar columnas
- Filtrar información
- Obtener estadísticas básicas

📂 `02_pandas_csv/`

---

### 🧹 03 - Limpieza de datos

Aquí comenzaremos a enfrentarnos a uno de los problemas más comunes al trabajar con datos: **los datos imperfectos**.

Trabajaremos con:

- Valores nulos
- Datos duplicados
- Datos inconsistentes
- Tipos de datos incorrectos
- Valores faltantes
- Conversión de tipos
- Reemplazo de valores
- Eliminación de información
- Preparación de datasets

📂 `03_limpieza_datos/`

## Metodología

La serie está enfocada en **aprender haciendo**.

En cada tema:

1. Explicamos el concepto.
2. Lo llevamos inmediatamente a Python.
3. Probamos diferentes casos.
4. Analizamos los resultados.
5. Trabajamos con datos.
6. Encontramos problemas.
7. Construimos soluciones mediante código.

El objetivo es comprender el código y aprender a utilizarlo en situaciones reales.
